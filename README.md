## Featured project

### [GenomQC RNA-seq QC Pipeline](https://github.com/muhammetozcelik/genomqc-rnaseq-qc)

A tested workflow for paired-end RNA-seq FASTQ files that provides:

- FASTQ structure and read-pair validation;
- raw and post-trimming quality control;
- conservative paired-end preprocessing;
- SHA-256 input and output manifests;
- software and parameter provenance;
- consolidated MultiQC reporting;
- automated unit and integration tests.

[View the live example MultiQC report](https://muhammetozcelik.github.io/genomqc-rnaseq-qc/demo/)
